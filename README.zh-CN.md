# Music Studio 0.5.16

Minecraft **1.21.1** / NeoForge **21.1.252** / Java **21**，依赖 **LDLib2 2.2.42**。

## 运行

将 `musicstudio-neoforge-1.21.1-0.5.16.jar` 放在目标游戏实例的 `mods/`，移走旧版 JAR 后重启该实例。进入世界后使用：

```text
/music editor
/music sounds
```

这是 NeoForge 客户端命令，不要求作弊权限。前者打开真正的 LDLib2 编辑器；后者直接打开音色/采样浏览器。此版本无需服务端权限来编辑本地工程，导出蓝图和放置需要创造模式；放置时会在服务器生成真实原版方块，多人游戏需要服务端也安装相同版本的本模组与 LDLib2。

## 音源、Pattern 与编曲轨道

0.5.0 将三者彻底分开：

- **Channel Rack（音源架）**管理乐器、声音事件和采样音源；底部 `+` 可添加音符盒/声音事件音源或导入采样音源。增删音源不增删编曲轨道。
- **Pattern** 是一份包含全部音源音符的乐段。一个实例只占一个片段，可反复放在任意轨道。修改这个 Pattern 内任一音源的音符，所有引用它的片段同步改变。双击 Pattern 片段直接打开对应 Pattern 的钢琴卷帘；卷帘折叠时自动展开，可用左上角列表选择音源。
- **Playlist 轨道**只负责摆放、显示和静音，可混放不同 Pattern 与多个独立音频片段；片段可上下跨轨拖动，轨道名称、颜色和显示高度独立于音源。
- **采样的两种用法**：从音源架 `+ → 采样音源` 导入后，由 Pattern 的音符/MIDI 控制音高、时值和力度；从左侧“音频”页签或媒体窗口导入，或从资源管理器拖入游戏，则创建独立音频片段，不创建 Pattern、不增加音源架声部。相同素材可同时采用两种用法。

左侧顶部“乐段 / 音源 / 音频”（英文 PAT / SRC / AUD）切换列表。Pattern 和音频列表支持拖到编曲区，也可先选中后点击轨道空白放置；源文件拖放使用鼠标所在的轨道与吸附位置。双击独立音频片段编辑裁切、淡入淡出和增益，片段显示实际素材 PCM 波形。Pattern 与音频片段均可按吸附拖动左右边缘裁切或补空白，不移动已有内容、不自动增加重复。

打开旧工程时，编辑器迁移为 schemaVersion=2。旧单音源片段分别关联到完整的单音源 Pattern，保留原有音符、重复、静音和时间，避免迁移后把其它音源重复播放；此后每个 Pattern 均支持继续添加多种音源。新版工程应使用 0.5.0 或更新版本打开，旧蓝图物品仍可使用。

## Pattern 删除与卷帘窗口

- 卷帘左上角的音源名称为下拉选择器，列出全部乐器/声音事件、采样音源和独立音频；可按名称或声音 ID 搜索，滚轮/右侧滑块浏览，↑↓ / Page Up / Page Down 移动选择，Enter 确认，Esc 或点击外部收起。切换音源保持当前 Pattern 和横向时间视野，直接编辑该音源在当前 Pattern 内的音符。
- 卷帘标题栏的 Pattern 下拉列表可直接切换乐段，窗口最大化后也能操作。选择采样音源后，“选择声音”按钮打开对应的采样编辑器。
- 独立音频标记“音频 → 采样”，选择后将该素材和当前处理参数复制为一个可用 MIDI 音符控制的采样音源；原有独立音频片段和设置保持独立。再次选择同一独立音频会复用已建立的音源，保存后仍可复用；建立音源可撤销/重做。
- 左侧“乐段”列表右键 Pattern，在设置里点击“删除 Pattern”。删除该 Pattern 及其全部编曲实例，保留其他 Pattern、独立音频、音源和轨道；Ctrl+Z / Ctrl+Y 可完整恢复。删除最后一个时自动补一个新的空白 Pattern。
- 右键音源架内的名称，选择“替换乐器 / 声音事件”或“替换为音频 / 采样音源”。替换保留原音源标识、名称、全部 Pattern 音符和编曲引用，不额外创建音源；替换文件后裁切、淡入淡出与增益恢复为新素材的默认值。取消文件选择或异步导入时项目已改变，都不替换现有音源。
- 钢琴卷帘窗口四边及四角可拖动调整大小；右上角方框按钮最大化，再点还原之前的位置和大小。最大化覆盖工作区，音乐编辑仍使用同一份数据。
- 卷帘底部横向条浏览时间，右侧纵向条浏览音高；均支持拖动滑块、拖动滑块两端缩放、鼠标悬停后滚轮缩放。卷帘主体普通滚轮上下浏览音高，Ctrl+滚轮缩放时间并尽量保持指针处的音符时间不变。缩放和平移不改变音符时值、力度或音高。
- 点击卷帘左侧白键或黑键使用当前音源试听；采样音源也会处理素材并播放。点击钢琴键不会创建音符。
- 双击编曲轨道标题或上下高度调节边缘恢复 65 个布局像素的默认高度；可撤销/重做，其他轨道不变。

## 窗口与导出范围

Music Editor 主界面、音源架、钢琴卷帘和全部设置/导入导出窗口，右上角统一提供折叠、最大化/还原、关闭三个按钮。折叠保留内容与窗口状态；设置窗口折叠后在底部留下标题条，点击 `+` 展开。主编辑器还原后居中缩小，再次最大化恢复完整工作区。关闭主编辑器沿用自动保存机制。

Playlist 标尺新增青色“曲首”和橙色“曲尾”导出游标，分别位于标尺上下半部，重叠时仍可独立拖动，按当前吸附定位。顶部“曲首 / 曲尾”按钮可将相应游标设到播放头，“全曲”按钮将两者重置重叠。

- 两个导出游标重叠：从曲首导出到最后一个有效声音结束，忽略工程总长度、Pattern 自动留白和片段尾部空白。音频及唱片按实际解码、变调和裁切后的声音计算，保留自然尾音；MIDI 到最后有效事件的 note-off；建筑保留实际声音尾部，并向上量化到红石时间格。
- 两个游标分开：只导出两者之间的范围，交换左右顺序也有效；起始、结尾和中间留白全部保留，支持选择实际曲尾之外的纯静音区间。
- WAV / MP3 / OGG、唱片、MIDI 分轨和红石蓝图均使用该范围，并继续排除静音轨道。音频保留选区起点处仍在衰减的声音；MIDI 与建筑将选区起点重定位到零。红石建筑仍受游戏 tick 量化与循环线路最短周期限制。
- 导出游标随工程保存，可撤销/重做；不改变试听范围、原始片段或工程实际时长。

## 播放起点与跳转

Playlist 整体编曲和钢琴卷帘的标尺均可点按、拖动：

- **停止时**按当前吸附设置绿线；绿线就是下一次播放的起点。
- **播放时**绿线按实际播放时间移动，播放中拖动标尺，松开后跳到目标位置继续播放。
- 点击停止、再次点击播放按钮或按空格停止，均回到本次播放之前设置的起点；播放中跳转不覆盖这个起点。非循环播放自然结束也回到起点，循环播放按当前播放范围回绕。
- 卷帘内提供独立播放/停止按钮，最大化后也可操作。Song 模式下，卷帘将 Pattern 局部位置换算到 Playlist 中的片段：优先当前选中实例，其次最近的有效实例，考虑左侧裁切、留白及已有重复。Pattern 尚未放置或目标位置已被所有实例裁掉时，改用 Pattern 模式试听。
- 点击整体编曲标尺进入 Song 模式；直接拖动或缩放滚动条只改变视野，不改变播放起点。导出用的青色/橙色双游标仍独立于绿色播放头。

## 卷帘视野与 Pattern 自动增长

卷帘时间视野独立于当前 Pattern 长度。可向后翻页、拖动横向条浏览空白，Ctrl+滚轮或悬停横向条滚轮持续缩放，滑块两端也可缩放；右边缘拖动音符会自动向后平移。缩放和平移均不修改乐曲内容，也不再以 Pattern 末尾限制滚动条。

新建、移动、拉长音符、数字时值输入、粘贴和 MIDI 导入均可延长 Pattern。长度取所有音源的最晚音符结束位置，向上对齐到小节，再额外保留一整小节休止；已有较长空间保留，不自动缩短。完整 Pattern 的所有编曲实例同步增长，包含整份内容的手动前后留白也保留原有空白长度。手动裁短的片段与旧的多次重复片段保持现有播放窗口，独立音频不受影响。增长、相关片段尺寸和编曲总时长包含在同一条撤销记录里。

原来的 256 小节 Pattern 限制已移除，Pattern 与卷帘使用整个工程的时间范围。横向显示可从 1 PPQ 缩放到 131072 小节；这是整数时间精度边界，与当前 Pattern 的长短无关。音频渲染和红石建筑各自的时长、资源及尺寸限制仍按导出窗口报告。

## 已实现

- 参考 FL Studio 风格的深灰工具栏、Playlist、浮动 Channel Rack、浮动 Piano Roll。
- 完整中英文界面，默认跟随游戏语言；顶部语言按钮可切换“自动 / 中文 / English”。用户输入的工程、通道和 Pattern 名称保持原文。
- 字体按实际屏幕像素对齐，默认 115% 字号，最小 14 物理像素行高；顶部 A− / A+ 调节字号，截断标签可悬停查看全文。
- 可独立删除音源和编曲轨道：删除音源清理 Pattern 中对应声部，保留 Pattern 片段与轨道；删除编曲轨道仅清理该轨道上的片段，保留音源、Pattern 和原始素材。可撤销/重做。
- 初始两小节多音源 Pattern、8 个音源、8 条独立编曲轨道、16 小节编曲；最多 128 个音源、256 条编曲轨道；独立音频源不设固定数量上限。
- Pattern 引用、步进开关、静音、片段放置/移动/裁切/删除、双击 Pattern 片段打开钢琴卷帘、双击独立音频打开素材编辑器。
- 片段左右边缘按当前吸附裁切或补留白：保留已有音符的绝对位置，拉长不会自动增加重复；旧工程已有的重复段保持原样。裁切后拉回可恢复原有内容，复制、保存与撤销保留源窗口及留白。
- Playlist 只保留曲首、曲尾两个导出游标；将曲尾拖到音符结束之后即可让导出包含末尾留白。两个游标重叠时恢复全曲导出。
- 音符绘制、移动、音高/长度拖动、力度栏拖动、数字力度/时值编辑。
- 音符及编曲片段的框选、Ctrl 点选、全选、成组拖动、复制/剪切/粘贴、批量删除；剪切、粘贴与整次拖动各占一条撤销记录。
- Song/Pattern 试听、停止回到起点、播放中跳转、速度设置和循环。试听使用实际游戏音频，而非浏览器合成。
- 系统文件窗口保存、另存为、打开 `.musicstudio` 乐曲工程；一个项目一个文件夹，乐谱和素材放在一起，兼容旧 JSON 工程；原子替换、上一版 `.bak` 备份、自动保存和草稿恢复。
- 上下两条同步横向滚动条、右侧纵向滚动条，支持滑块拖动与悬停滚轮缩放；时间线连续缩放与向后延展、轨道独立高度、改名、染色、左侧乐段/音源/音频分页列表。
- 所有当前注册 SoundEvent 与资源包 `sounds.json` 事件的并集扫描；按完整 ID、命名空间、音色名称搜索。
- 所有固定音符盒乐器的声音映射：16 种基础乐器与 6 种生物头颅声音。额外匹配模组命名中包含 `note_block` 的声音，仍可在全部声音中按完整 ID 选择任何模组事件。
- 声音单击试听、双击/Enter 绑定当前音源。注册存在但客户端缺少音频资源的事件标为 `NO AUDIO`，不会假装可播放。
- F3+T 或切换资源包后重新扫描；也可点击 `Rescan`。
- 原版红石音乐蓝图：红石粉、中继器、比较器、原版音符盒及音色基座/头颅，单次版起点带石按钮，循环版起点带拉杆。正常音符不使用自定义播放方块、后台调度或音频包。
- 全曲 Playlist 导出、实际尺寸/方块数/量化误差报告、循环或单次线路、蓝图物品快照、创造模式手持包围框、旋转和分批安全放置。
- MIDI 导入、逐轨独立 MIDI 文件导出；WAV / MP3 / OGG 全曲混音导出；可插入原版唱片机的唱片物品导出。
- 项目内素材导入、波形裁切、淡入淡出、增益和撤销/重做；采样试听、混音和命令方块资源使用同一组素材处理参数。
- 勾选命令采样后，非音符盒声音生成原版命令方块，执行原版 `playsound`。

`CUSTOM_HEAD` 没有固定音色，其声音取决于头颅的 `note_block_sound` 数据。它不是 `ui.button.click`，因此不把枚举中的占位声音当作音色展示；实际声音事件从全部声音目录选择。

声音事件的底层随机变体、别名和资源包替换由 Minecraft SoundManager 解析，尊重当前资源优先级。扫描范围是声音事件，不是把没有事件定义的磁盘 OGG 文件当作 `/playsound` 参数。资源缺失/损坏仍需修复资源包。

0.4.0 将时间标尺与滚动条分开：绿色光标点击/拖动仍按所选吸附定位；上下横向滚动条用来左右浏览，两个位置同步，拖动滑块两端可缩放。鼠标在时间线主体时普通滚轮上下浏览，Ctrl+滚轮连续缩放；鼠标在横向滚动条上直接滚轮缩放时间，在右侧纵向条上滚轮缩放轨道高度。小节网格和编号随缩放密度调整，不再限制只能显示 4–16 小节。视窗支持单 PPQ 精度至 131072 小节的数值范围，工程编辑可延展到相同范围；声音混音、MIDI 导入和红石模板仍保留各自的实际容量限制。

浏览可以超过现有曲尾；在后面的空白处放片段、移动、粘贴或拉长片段会自动延长整曲时长。片段或播放光标拖到视窗边缘时继续平移视窗，片段跨轨拖动靠近上下边缘时滚动轨道。每条编曲轨道默认 65 个布局像素，新增轨道不会把其他轨道压小，拖动上/下边缘可独立调整 32–600 像素。轨道、音源和 Pattern 分别保存名称与颜色，Pattern 片段采用 Pattern 颜色，音频片段采用独立音频源颜色。

“文件”菜单提供保存、另存为、从系统打开；工具栏“打开”也直接调用系统文件窗口。首次保存会根据所选 `.musicstudio` 文件名创建同名项目文件夹，之后 Ctrl+S 保存到当前文件；Ctrl+Shift+S 另存为，Ctrl+O 打开。项目文件与 `assets/` 放在同一个文件夹，素材直接从相邻目录读取，不再解包到另一个 UUID 工程目录。分发时复制整个项目文件夹；外层文件夹、内部 `.musicstudio` 文件都可以独立改名，重新打开即可，二者不必同名。也可以把项目文件夹直接拖进编辑器打开。保存先写临时文件并原子替换，旧版保留为 .bak；关闭编辑器仍会自动保存本机草稿。旧版 .json 可打开；带采样的旧工程需同时带上其 UUID 素材文件夹。

快捷键作用于最近操作的 Piano Roll 或 Playlist；两者也各有 Copy/Cut/Paste 按钮。音符粘贴保持相对时间、音高、时值和力度，可以换到其他通道或 Pattern；片段粘贴保留原轨道及 Pattern 引用。每次粘贴后，插入位置前移到此次选区的末尾，便于连续粘贴。

音符粘贴超出 Pattern 末尾、事件数量上限或缺失轨道时，整次拒绝并提示，不截掉一部分内容；编曲片段粘贴到现有曲尾之后会自动延长乐曲。乐谱剪贴板在本次客户端会话内保留；编曲片段目前仅支持原工程内粘贴，音符支持跨工程复制。片段保持引用关系，编辑其 Pattern 会影响同 Pattern 的其他片段。

片段剪贴板按稳定编曲轨道标识关联，保留 Pattern/独立音频引用和留白；删除较早的轨道后，仍粘贴到原来的存活轨道；原轨道或音频源已删除时整次拒绝。音符复制可以在不同音源间粘贴。

文本框拥有焦点时优先处理文本；Ctrl+A 全选，Ctrl+C/X/V 使用系统文本剪贴板，不会剪掉乐谱。自动保存名称和相对资源路径经过校验；显式保存只写入用户在系统文件窗口选择的位置。老版本工程加载后自动补齐稳定的工程、通道和 Pattern 标识，旧文件可读取并迁移；新版文件需要新版模组打开。

## 保存位置

在**实际游戏实例目录**的 `musicstudio/projects/`：

- `<文件名>/<文件名>.musicstudio`：显式保存的乐谱，与同目录的 `assets/` 一起构成完整项目。
- `<文件名>/assets/`：原始素材、标准 WAV 及可重建的效果缓存；分发时随项目文件夹一起复制。
- `.drafts/<工程ID>/`：未命名草稿和自动恢复素材的本机缓存，不是项目分发所需文件。
- `<工程名>.json`：可继续读取的旧版乐谱。
- `<工程名>.json.bak`：前一版。
- `autosave.json`：草稿自动保存。

默认目标实例：`D:\game\.minecraft\versions\1.21.1-NeoForge_21.1.252`。

语言和字号偏好单独保存在实例的 `musicstudio/client.json`，不改动游戏全局语言或 LDLib2 配置。

## 音乐蓝图与原版电路

1. 在 Playlist 放好乐句。导出始终编译完整编曲，不取当前 Pattern 的独立试听内容。
2. 打开“导出蓝图”，设置最大 X/Z/Y、循环、命令采样和扩展音符盒模式。界面显示实际占地、方块数、起点最大误差及量化周期；尺寸不足时拒绝生成，不压缩或截掉曲子。
3. 创造模式点击“生成音乐蓝图物品”，背包需留空位。蓝图保存此次乐谱的独立快照，之后编辑不会改变已有物品。
4. 手持蓝图指向方块外侧，可见真实包围框和黄色起点开关标记；绿色为本地可放置，红色为受阻。潜行右键旋转，只提供仍满足原长宽限制的朝向。
5. 右键放置后，按提示坐标找到起点开关。单次版使用原版石按钮，按下播放一次、自动回弹，乐曲结束后可再次按下；循环版使用原版拉杆，打开持续循环。放置时都不会自动播放。
6. 循环版关掉拉杆后，等待**整曲量化时长 + 4 游戏刻**让在途信号排空，再重新打开。关闭不是瞬间取消所有已进入中继器的信号；原版音符盒的自然尾音也不会被强制切掉。

原版音符盒以两游戏刻为最小编译时间格；相同时间格的音符并行触发，最多 16 个。延时由实际中继器档位实现，折行/多层由红石粉阶梯连接。循环版加入原版减法比较器时钟和实体反馈路径，周期量化为四游戏刻的倍数，最小 12 游戏刻。起点有固定约四游戏刻的电路启动延时，音符之间的时间差按编译结果执行。TPS 下降会按原版红石规则放慢播放。

0.3.1 的建筑按每个音符决定播放方块，同轨可以混用：

- 静音轨道完全排除，不生成音色、音符、命令方块，也不消耗和弦数量或建筑占地；整曲时间线和循环周期仍由工程曲长决定。
- 左键在卷帘或 Channel Rack 创建音符盒音符时，默认力度为 127、时值显示为 1 格。这里的 1 格代表原版的一次触发及自然衰减，不是强制把声音截成一个十六分音符；试听和音频混音也保留其自然尾音。MIDI 只保存数值时值。
- 时值为 1 格且力度为 127：放置原版音符盒及音色基座；6 种生物音色放置对应头颅。音高超出 F#3–F#5 会限制到端点，并报告数量。
- 修改力度或时值：仅该音符自动改用真实命令方块，无需勾选“命令方块采样”。力度换算为 playsound 音量；非默认时值会从当前资源包的实际音色、音高生成独立裁切 OGG，然后执行 playsound 播放该文件；不使用会误停其他声音的全局 stopsound。恢复到默认值后又会生成音符盒。
- 裁切音频沿用编辑器的采样规则：到指定音符时值截止，若原素材更早自然结束则不人为合成延音。首次导出会生成并同步这些音频，使用相同参数会复用内容缓存。命令方块仍需要 2 级管理权限及服务器启用命令方块。

自动替换只写入此次蓝图的独立快照，不改工程中的通道音色、音符或静音状态。MIDI、WAV/MP3/OGG 和唱片继续直接导出乐谱/混音，不经过建筑替换步骤；导出唱片不要求建筑能排布成功。旧版 version=2 蓝图物品继续按其原先的纯原版规则解码，新导出的 version=3 蓝图采用逐音符规则。

任意其他声音需要勾选“命令方块采样”，或把通道改成音符盒音色；不会偷偷换音色或跳过通道。命令模式需要服务器启用命令方块和 2 级管理权限。生成的命令仅为白名单格式的 `playsound <声音ID> record @a[distance=..64] ~ ~ ~ <音量> <音高> 0`，由真实红石供电触发，有原版命令方块的一游戏刻执行延时；使用处理后素材的自然音长；导入素材可先在采样编辑器裁切。

放置在服务端重新验证创造权限、空地、世界边界/高度、已加载区块和保护事件；每 tick 最多写入 256 个方块，施工失败或被保护事件拒绝会回滚本次写入，保留外部后来改动的方块并记录异常坐标。整个包围盒都要为空，包含音符盒上方净空。建筑放好后完全由原版机制运行，保存/重进遵循原版方块与计划 tick 的行为；请保持整座线路在运行区块范围内。

当前布局模板有固定的音符扇出、蛇形折行、多层和窄 U 形循环时钟；最多 4096 个展开音符、32768 个方块、131072 格包围体积。某些较长乐曲或较紧尺寸可能无法由当前模板排布，失败只表示当前算法未找到布局。默认 16 小节示例的音符盒轨道可在 48×32×12 内生成；示例中的环境声和拟音需要启用命令采样或静音。


试听保留当前声音资源的音色/随机变体；短素材仍按实际素材长度播放。音符结束按编辑器持有的声音实例独立停止。

0.5.6 起，卷帘钢琴键试听、音符试听、Song/Pattern 播放、采样音源、波形和 WAV/MP3/OGG/唱片导出使用完整 MIDI 0–127 音高，按 `2^((音高−基准音高)/12)` 计算，不再将高低音限制在 0.5–2 倍速。声音资源自身的 pitch 参数仍参与计算。本模组的声音实例单独绕过 Minecraft 的音高钳制，其他游戏声音维持原有行为。

建筑导出中，默认时值/力度且位于原版 25 音域内的音符继续使用原版音符盒。超出音域的音符自动生成按实际音高烘焙的采样，由真实命令方块以 1 倍音高播放，不用原版最高/最低音替代；这些音符和改时值/力度的音符一样，不需要额外勾选“命令方块采样”。非音符盒声音/独立采样的建筑导出仍使用原有采样开关。默认自然衰减的音符在变调采样里保留实际衰减，修改时值的音符继续按编辑后的时值处理。

Piano Roll 使用连续时间与音高视图，默认显示两小节，横向滚动及页移按钮可浏览整个 Pattern；可见时间与半音范围均可缩放。最多 128 个音源；Playlist 和 Channel Rack 分别支持轨道滚动与音源翻动。完整混音器、VST 和频谱分析尚未实现。

## 顶部真实混音波形

0.4.1 替换了原先跟随播放位置计算的装饰动画。顶部小波形框现在从 Minecraft 当前资源包实际音频和项目采样生成 PCM 混音，复用 WAV/MP3/OGG 导出的同一套混音器；包含音符起点、音高、时值、力度、通道音量、静音和采样裁切/淡入淡出/增益。先把声波相加再计算左右声道的正负峰值，因此休止、静音、相位抵消也能如实显示。

停止或暂停时显示全曲/当前 Pattern 的概览及绿色播放位置；播放时默认显示播放位置之前 200 毫秒的局部波形。点击波形框可以在播放时切换概览和局部波形，悬停可查看说明。修改乐谱后延迟约 0.4 秒在后台更新，过期计算可取消，结果尚未准备好时显示省略号；音频缺失或超过容量时显示提示，不使用合成动画代替。

波形是工程音频的混音快照，不采集扬声器、世界环境声或语音。游戏随机音效按音频导出使用的固定变体解析，实际游戏每次随机播放的素材可能有所不同。整体峰值超出音频导出范围时，与导出相同地统一降低增益；坐标轴不做逐帧自动增益。波形与混音不设固定时长或解码源时长预算；窗口缩放与滚动不需要重新混音。

## MIDI、音频、唱片与采样

顶部“媒体 / Media”按钮打开导入导出窗口。**轨道静音按钮是统一的导出选择器**：静音轨道不进入 MIDI 分轨文件、WAV/MP3/OGG 混音、唱片或红石蓝图；要只导出几个轨道，把其他轨道静音即可。显式采样试听仍可试听当前静音轨道。

- MIDI 导出在所选目录中新建 MIDI-时间戳 文件夹，每个包含音符的未静音编曲轨道一个标准 .mid 文件；文件内按音源分 MIDI 声部，包含该轨道所有 Pattern 实例的音高、起点、时值与力度。独立音频不伪装成 MIDI 音符。MIDI 不包含游戏音频、采样素材或音频效果。
- MIDI 导入支持常见 PPQ 格式的 type 0/1 文件，按来源 Track + MIDI Channel 创建最多 32 个音源声部，统一放进一个 Pattern 和一个编曲片段。保留音符/力度/时值；变速 MIDI 折算成一个编辑器 BPM 并保持绝对播放时间，显示折算次数。GM 乐器近似映射到音符盒音色，可自行改音色。SMPTE 时间制暂不支持，控制器、弯音、踏板等不支持的信息会报告数量。
- 音频导出为一次完整 Playlist，不无限循环；支持 44.1 kHz、立体声、16 位 PCM WAV，192 kbps MP3 和 Vorbis OGG。读取 Minecraft 当前资源包实际解析的游戏声音，也包含模组声音；随机变体在每轨导出时按固定种子选取，成品不会混入环境声、界面声或语音。尊重通道音量、音符力度/音高/时值和采样处理；必要时统一降低总增益以避免混音削波，结果显示增益系数。
- “导出为唱片”将当前未静音轨道混音成 OGG，上传当前世界并生成“音乐工作室唱片”物品。创造模式导出，之后可正常插入/弹出原版唱片机、保存物品、由漏斗操作；唱片机有比较器输出和音符粒子，实际时长结束或弹出后停止声音。唱片保存此次混音快照，不随工程后来修改变化。
- 导入 WAV / MP3 / OGG / FLAC / AIFF / M4A 素材默认创建独立音频片段，放在当前轨道和吸附位置；从音源架 `+` 导入则只创建可由音符控制的采样音源。原文件和统一格式副本保存在项目自己的 assets 文件夹中。双击音频片段或选择采样音源后点击音源架“音色 / 采样”进入编辑器，支持起止秒数、淡入淡出、0–4 倍增益和撤销/重做。
- 两种采样导出建筑都需要启用命令方块采样。建筑中每个事件使用匹配其裁切偏移、音高和时值的 OGG，真实命令方块执行原版 playsound，因此左边缘裁切和音符时值也作用于建筑；不再用整段未裁切素材代替。音量、距离衰减遵守原版规则。

0.5.12 起命名保存使用 `项目名/项目名.musicstudio` 与相邻的 `assets/`，复制这个项目文件夹即可迁移和分发，不需要复制整个实例或 `musicstudio/projects/`。旧 JSON/UUID 素材目录和旧版单文件 ZIP 工程仍可打开，下一次显式保存可整理为新的项目文件夹；旧文件与旧缓存不自动删除。世界服务器的独立音频副本位于该存档 musicstudio-media/；多人加入时会按内容哈希同步素材到客户端 musicstudio/media/，自动维护并启用 musicstudio-generated 资源包。首次载入新素材会触发资源重载，完成后再播放。转移唱片或蓝图到缺少素材的另一世界时，需要从原项目重新导出。

音频导入、混音、导出、唱片、项目素材和服务器共享音频库不设固定大小、时长、素材数量或总容量上限；实际处理能力取决于可用内存、磁盘及文件格式。文件复制、哈希校验和同步按块处理，编解码不再按固定秒数截断或超时；同步超时只针对持续无进展的传输。素材采用裁切和普通变调重采样，不是保持音高的时间拉伸。首次构建/installMod 会把随工作区提供的 Windows FFmpeg 编码器及许可说明安装到实例 musicstudio/tools/，不需要额外配置 PATH；单独拷贝 JAR 时还应带上该工具目录。

## 0.5.11 扩展音符盒模式

## 0.5.12 一个项目一个文件夹

例如选择保存为“夜航.musicstudio”，会生成：

```text
夜航/
  夜航.musicstudio
  assets/
```

复制或压缩整个“夜航”文件夹即可分发；对方在安装本模组的游戏中打开里面的 `.musicstudio` 文件，或把文件夹拖进编辑器。项目文件夹名、文件名和工程标题互不绑定，后续分别改名、移动到其他磁盘或复制到另一台电脑均可。普通保存继续写入实际打开的文件，不根据旧名字重建目录；另存为复制乐谱和所需素材，并切换到新项目目录。素材依赖第三方模组音色时仍需要对应模组或资源包。

新版 `.musicstudio` 文件保存乐谱，原始采样与标准 WAV 位于相邻的 `assets/`。工程内容不保存绝对路径；撤销、重做、预览、混音和蓝图准备的工作副本保留当前目录绑定。旧版打包的 `.musicstudio` 文件仍能打开，保存时迁移为项目文件夹；旧版原件保留。自动恢复会在本机缓存素材，不向已保存的项目文件夹额外写 `project.json`。

验证：154 个单元测试；230 阶段编曲客户端回归；项目文件夹客户端闭环覆盖首次保存、普通保存、另存为、文件和文件夹独立改名、文件夹拖入打开、撤销/重做、真实采样播放及 WAV 导出。另存为保留可重做导入的源文件；复制到空缓存位置后仍可混音，缺少相邻素材时不会假装从其他项目加载成功。报告为 `build/reports/project-folder-client-0.5.12.log`、`project-folder-arrangement-0.5.12.log`。
